# 可布置的 3D 小屋

小屋选人后，原 2D 房间顶部的「3D 小屋」打开可选的立体布置模式；「2D 小屋」返回。既有 `roomConfig` 不迁移、不覆盖。

## 布置与数据

- 27 类家具资产支持移动、90° 旋转、主色更换、复制和收纳。家具架分为地毯、桌台、桌上小物、落地、墙饰、吊挂。挂墙资产沿墙移动；楼梯和阁楼保留组合关系。
- 圆茶几和空白小书桌提供圆形 / 矩形承托面，台面形状与高度来自资产目录；书、茶杯、水母夜灯、小盆栽是独立桌上资产。原水母工作桌保留固定摆件套组，暂不提供自由台面。
- `supportId` 记录同房间桌上物件所属桌台；移动、旋转、整组收纳和跨房间恢复保持相对位置。物件能单独收纳和重新放置。检查台面边界、悬空及物件间碰撞；拖动会按目标台面高度吸附。仅布置操作时检查，不进行逐帧刚体模拟。
- `assetVersion: 2` 兼容旧布置；旧茶几转换为独立摆件时保留桌台身份与位置，可用台面不足时不强塞摆件。旧版未承托的小盆栽进入收纳箱。
- 收纳箱跨房间共享，搬到另一间时保留家具 ID 和配色。新房间默认空置。
- 房间向前后左右扩展，也可增加楼层；最多 24 间、6 层。上层需要正下方有房间支撑。
- `CharacterProfile.home3D` 保存版本化房间坐标、家具实例和颜色；完整角色备份包含此字段，角色卡导出剥离此运行时字段。
- 支持撤销、JSON 布置导入导出；导入检查版本、容量、坐标、资产 ID 等。还没有角色行走、寻路或跨房间行为系统。

## 源文件与生成

`art/jellyfish-home/export_kit.py` 从已有 Blender 场景提取模块，按资产内的材质合并静态几何，保留水母动画节点。输出 `public/room3d/kit.glb` 和 `catalog.json`。Blender 是资产制作端，Three.js 是实时显示与交互端。

`apps/room3d/model.js` 管理纯数据和碰撞约束；`editor.js` 管理渲染与编辑；`Home3DView.tsx` 连接 React 生命周期和角色保存。

独立预览：运行 `node art/jellyfish-home/editor-build.mjs`，再运行 `node art/jellyfish-home/server.mjs`，打开 `http://127.0.0.1:4178/assets/editor.html`。预览存储与应用角色数据分开。

## 渲染预算

2026-09-13 更新：默认使用省电档，画质设置保存在当前设备的 `sully-home3d-quality`，不跟随角色导出。省电 / 均衡 / 清晰的像素倍率上限分别为 0.75 / 1 / 1.5。省电关闭阴影与动画，总览只细绘一间；均衡细绘两间，清晰触屏两间 / 桌面四间。省电与其他静态场景在相机稳定后停止 RAF 调度，操作、尺寸改变或页面恢复时唤醒；以下此前预算以对应开启效果的档位为准。

装扮支持整屋主题及独立墙面、边框 / 底座、地板颜色（`wall`、`trim`、`floor`）。布置模式提供 45° 视角按钮及拖动视角切换，切换到视角模式时不拖动家具。

交互修订：取消独立的拖动视角模式。点击家具选中，再拖选中家具移动；拖其他区域转视角，滚轮 / 双指缩放，右侧常驻缩放和 45° 转向按钮。双指接管时取消单指家具拖动，避免误放。选中只显示底部约 106px 的工具条和底部轮廓，色块按需展开。顶部提供撤销 / 重做，快捷键 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z 或 Ctrl/Cmd+Y。家具修改不重置镜头，关闭镜头惯性方便精确摆放。

- 单间仅创建当前房间；总览最多显示触屏 2 间 / 桌面 4 间的完整家具，其余为共享几何的简化房壳。
- 实例共享几何与同色材质；重建时清理闲置材质及连接块资源。卸载释放渲染器、阴影、几何和纹理，并取消加载及动画循环。
- DPR 上限 1.5，触屏绘制上限 30 帧 / 秒，桌面上限 60 帧 / 秒。这个上限不是实际帧率保证。
- 仅单间使用缓存阴影，布置变化时更新；总览关闭阴影和呼吸动画，静止时不重绘。
- 页面隐藏时停止绘制；系统减少动态效果开启时，单间也按需绘制。

## 验证记录

2026-09-13：7 项模型测试通过；浏览器验证拖动、旋转、换色、跨房间搬运、平面扩建、楼层和刷新恢复。独立 React 测试使用真实 OSProvider / RoomApp / IndexedDB，验证 2D → 3D → 2D → 3D 保存恢复且原房间配置不变。

触屏配置的 Edge 软件 WebGL 压力检查：24 间已布置房间，总览约 30.5 万三角形、461 次绘制调用；单间约 15.2 万三角形、170 次绘制调用。往返切换总览八轮，几何 / 纹理 / 材质计数稳定；减少动态效果和总览静止时均不继续绘制。计数为当前画面的 renderer.info，不代表真实手机帧率，仍需真机验证发热、耗电和低端 GPU 表现。

脚本：`art/jellyfish-home/editor-qa.mjs`、`performance-qa.mjs`、`integration-qa.mjs`；结果在忽略的 `output/jellyfish-home/` 中。测试使用独立浏览器存储，不修改用户角色。

台面更新：10 项模型测试通过；`support-qa.mjs` 验证分类、无桌台拒绝摆放、跟随旋转、成组跨楼层收纳恢复、单独收纳和刷新保存。

`quality-qa.mjs` 验证整屋配色保存、布置中按钮及拖动旋转不改变家具、三档真实像素倍率、切档后的省电静止无绘制和刷新恢复。生产构建通过；没有测量真实手机功耗或承诺帧率。

`interaction-qa.mjs` 验证点击选中不修改存档、不弹大面板、撤销重做、按钮及滚轮缩放、空白拖动、真实浏览器双指触摸缩放不改家具、选中拖动和保留镜头。选择工具条截图已人工检查。

选中反馈：家具使用两层复用原几何的轻量外扩描边（奶油亮边 + 淡紫光晕），不使用全屏泛光。只为当前选中物件创建；取消或退出布置即移除。拖动落地家具时显示程序化地面网格（0.4 主格 / 0.2 细格）及半透明占地，合法绿色、碰撞或越界红色。桌上物件在承托高度显示占地；墙饰不显示地面落点。仅操作时重绘，省电档不持续闪烁。

`placement-guide-qa.mjs` 验证选中描边、合法/非法拖动提示、非法落点回退、八轮选择资源稳定、退出布置后无覆盖效果且停止绘制；截图人工检查。
